# AGENTS.md

- Less, but better.
- Correctness beats cleverness, breadth, and speed.
- Keep APIs small, explicit, and boring.
- Preserve provider message ordering, especially tool-call/tool-result pairs.
- Make durability and compaction boundaries explicit.
- Prefer clear errors over hidden recovery.
- Tests should cover behavior, ordering, and failure paths.
- Optimize for DX: predictable names, simple examples, no surprise state.
